# ClipDesk 0.4.3 — catálogo de plugins unificado

## Novidades

- ClipDesk e ClipDesk DEV consultam o mesmo catálogo oficial de plugins na branch `main`.
- O plugin opcional Texto para Fala está disponível na loja, com geração de áudio online e alternativa local no Windows.
- A publicação de um novo plugin depende do pacote e de sua entrada no catálogo oficial, sem exigir nova versão do aplicativo.
- O ClipDesk DEV deixou de apontar automaticamente para um servidor local de publicação. Um servidor compartilhado pode ser configurado explicitamente quando necessário.

## Validação

- O pacote Texto para Fala publicado foi conferido com o SHA-256 do catálogo.
- As edições Production e DEV foram compiladas com o catálogo oficial.
- A instalação do pacote remoto e as verificações de núcleo, nuvem, interface, plugins e instalador foram executadas antes da distribuição.

As verificações automatizadas de nuvem não substituem uma sessão interativa com duas contas no Supabase de produção.
