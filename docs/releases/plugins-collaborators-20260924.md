# Plugins opcionais do ClipDesk

Pacotes publicados para o catálogo oficial:

- Relógio Mundial 1.0.0
- Conversor de Arquivos 1.0.0
- Compressor de Imagens 1.0.0
- Upscale de Imagem 1.0.0
- Cronômetro 1.0.0
- Temporizador 1.0.0
- Conversor de Fuso Horário 1.0.0

Os três plugins de arquivos exigem ClipDesk 0.4.2 ou posterior. O feed oficial informa essa versão mínima e verifica o SHA-256 de cada ZIP antes da instalação. Gerador de QR Code e Gravador de Áudio continuam nas suas Releases anteriores.
