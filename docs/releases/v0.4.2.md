# ClipDesk 0.4.2 — plugins de colaboradores

## Novidades

- A loja agora apresenta os plugins publicados no catálogo oficial: Gerador de QR Code, Gravador de Áudio, Relógio Mundial, Conversor de Arquivos, Compressor de Imagens, Upscale de Imagem, Cronômetro, Temporizador e Conversor de Fuso Horário, além dos quatro plugins incluídos no ClipDesk.
- Corrigida a compatibilidade do SDK Windows exigida pelos três plugins de arquivos. Conversão, compressão e ampliação de uma imagem de teste foram executadas com sucesso.
- O slider global do Dev Kit recebeu o design Minimal aprovado: trilho e thumb menores, com borda e sombra mais discretas, preservando a API e o comportamento.
- O Dev Kit para download foi atualizado com os controles Windows usados pelos plugins atuais.

## Validação

- O teste da loja confirma que todos os pacotes do feed aparecem e podem ser escolhidos para instalação.
- Os pacotes publicados têm seus manifestos e hashes conferidos com o catálogo.
- Os testes de mesa local, nuvem pessoal e mesa compartilhada, além das verificações de interface, plugins e instalador, foram executados antes da publicação.

Os testes automatizados de nuvem não substituem a revisão interativa entre duas contas no Supabase de produção.
