# ClipDesk 0.4.0 — plugins e personalização

## Novidades

- A mesa agora aceita plugins portáteis, com loja para adicionar, reparar, atualizar e remover pacotes opcionais. Calculadora, checklist, tradutor e conversor de moedas acompanham o aplicativo. A loja também oferece Gerador de QR Code e Gravador de Áudio.
- O [Dev Kit de plugins com IA](https://clipdesk.pages.dev/downloads/ClipDesk-Plugin-AI-DevKit.zip) traz o guia, os SDKs, um modelo inicial e o empacotador para criar plugins próprios.
- A interface ganhou opções de aparência para o fundo da mesa e para as fontes. Também há melhorias nos controles dos plugins, na seleção e no trabalho com arquivos.
- A sincronização preserva a identidade, a versão e o estado dos plugins em mesas pessoais na nuvem e em mesas compartilhadas. O servidor de testes foi ajustado para aceitar esses campos.
- O instalador Production sugere `C:\Program Files\ClipDesk`, solicita elevação do Windows e reconhece a instalação anterior em `%LocalAppData%\Programs\ClipDesk` para migrá-la mantendo os dados por padrão. O atualizador também pode gravar no novo local.
- A landing page explica como criar um plugin em três passos, oferece o Dev Kit e apresenta uma seção de novidades por lançamento com assinatura por feed.

## Validação desta entrega

- Compilação Production sem erros ou avisos.
- 39 verificações do núcleo, 68 de nuvem e colaboração, verificações visuais de mesa e instalador, e testes de loja, entrega, arquivos e contratos dos plugins aprovados.
- O instalador Production foi extraído em uma pasta temporária isolada: 538 arquivos, executável presente e destino padrão confirmado como `C:\Program Files\ClipDesk`.

Os testes automatizados de nuvem usam um servidor local e verificações de protocolo. A revisão interativa entre duas contas no Supabase de produção continua sendo a validação necessária para medir a experiência real de colaboração.
